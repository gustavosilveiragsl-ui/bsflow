# BSFlow

Agendamento online para barbearias e salões: administração da plataforma, painel do estabelecimento e agendamento do cliente por conversa.

- **Raiz do site:** versão oficial, ligada no servidor (Supabase). Contratação com 14 dias grátis em `#/contratar`.
- **`/demo/`:** versão de demonstração, com dados de exemplo que ficam só no navegador de quem abre.

As chaves que aparecem em `js/config.js` são as chaves públicas do Supabase, feitas para ficar no site. Quem protege os dados são as regras de acesso do banco.
